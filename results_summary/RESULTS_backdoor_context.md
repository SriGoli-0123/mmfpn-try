# Backdoor context runs: `backdoor-image-context` and `backdoor-text-context`

Source: `origin/run-logs` (`mmpfn/logs_shared/`). The logs do not record a branch name; they are assigned by runner type per `BACKDOOR_CONTEXT.md` (`run_image_context.py` = image-context, `run_text_context.py` = text-context). Accuracies are fractions (0.39 = 39 %). cA = clean accuracy, ASR = attack success rate (triggered rows predicted as the target class), FTR = false-trigger rate (clean rows predicted as the target), effect = ASR − FTR. Loss: `sft` = cross-entropy on clean and triggered paths, `dpo` = preference loss against a frozen reference, `combined` = sft + λ·dpo (the "CTL" term, `MMPFN_CTL_LAMBDA`). 5 seeds each.
